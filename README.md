# K2-quadrature — Калькулятор площади стен и пола

Калькулятор K2 поможет быстро и точно рассчитать площадь стен и пола по комнатам, учесть окна и двери, добавить запас на подрезку — и сразу получить итоговую таблицу.

## Возможности

- Расчёт площади стен с вычетом окон и дверей.
- Расчёт площади пола и потолка.
- Учёт запаса на подрезку (настраиваемый процент).
- Формирование итоговой таблицы с результатами.

## Как пользоваться

1. Откройте главную страницу проекта.
2. Перейдите в раздел «Калькулятор».
3. Введите параметры комнаты, окон и дверей.
4. Получите расчёт и таблицу с итоговыми значениями.

## Особенности

- Бесплатно, без регистрации.
- Работает на телефоне и компьютере.
- Все расчёты выполняются на стороне клиента (без отправки данных на сервер).
